# README

Agent Graph Designer is a mobile-friendly graph editor for designing AI agent workflows.

Current capabilities:
- Canvas node/edge editing
- Validation
- Specification / Coding Prompt generation
- Google ADK readiness and Python project generation
- ZIP export
- Local Bridge validation
- Local ADK execution
- Ollama / LiteLLM local model configuration
- ADK Event Trace visualization on the Canvas

Runtime policy: local-first. The Local Bridge binds to `127.0.0.1`, and Local Execution allows loopback network access only.
